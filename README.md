# 鲸小蓝 · DS

DeepSeek 社区蓝发鲸鱼娘形象的 Codex 桌宠，使用 AI 重新绘制，包含 9 组动作和 16 向视线。

![鲸小蓝挥手](动画预览/waving.gif)

## 下载与安装

下载 [桌宠分享压缩包](鲸小蓝-DS桌宠-分享版.zip)，解压后把 `ds-jingxiaolan` 文件夹放进 Codex 的 `pets` 目录。Windows 默认是 `%USERPROFILE%\.codex\pets\`，macOS/Linux 默认是 `~/.codex/pets/`；设置过 `CODEX_HOME` 时使用其下的 `pets` 目录。

在 Codex「设置 → 宠物」选择「鲸小蓝 · DS」，再使用 `/pet` 显示。详细步骤见 [使用说明](使用说明.md)。解压后双击 `预览.html` 可以离线预览全部动作与鼠标跟随视线。
