# 大肥鱼 · DS

以 DeepSeek 社区蓝发鲸鱼娘形象为参考，使用 AI 重新绘制的 Q 版桌宠，包含 9 组动作和 16 个视线方向，采用 v2 图集格式。

![大肥鱼挥手](动画预览/waving.gif)

## 下载与安装

下载 [大肥鱼桌宠分享压缩包](大肥鱼桌宠.zip)，完整解压后，将包含 `pet.json` 和 `spritesheet.webp` 的 `ds-jingxiaolan` 文件夹放入应用使用的 `pets` 目录。

注意：当前压缩包已更名，但包内仍为旧版说明和显示名。安装前，请用仓库当前的 `pet.json`、`使用说明.md`、`形象来源与署名.md` 和 `预览.html` 覆盖解压目录内的同名文件；展示图片可更名为 `大肥鱼桌宠.png`。

默认路径：
- Windows：`%USERPROFILE%\.codex\pets\`
- macOS/Linux：`~/.codex/pets/`
- 设置过 `CODEX_HOME`：使用该目录下的 `pets` 文件夹。

本包采用 v2 图集格式，需使用提供「设置 → 宠物」入口并能识别该格式的 Codex 桌面应用。v2 是图集格式版本，不是 Codex 应用版本号；本项目未核实最低兼容版本。

以上是本包沿用的本地安装方式。列出安装路径不代表已验证对应平台的兼容性。

安装后，在「设置 → 宠物」选择「大肥鱼 · DS」。宠物未显示时，输入 `/pet`，或在命令菜单中选择「显示宠物」（Show pet），以应用实际提供的入口为准。详细步骤与排查方法见 [使用说明](使用说明.md)。

完整解压后，双击 `预览.html` 可在浏览器中离线查看动作、切换深浅背景，并预览鼠标跟随视线。预览页不会安装或启动桌宠。
